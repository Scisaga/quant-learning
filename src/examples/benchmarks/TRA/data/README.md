# TRA 示例数据（用于论文复现/演示）

数据下载链接（Google Drive）：https://drive.google.com/drive/folders/1fMqZYSeLyrHiWmVzygeI4sw3vp5Gt8cY?usp=sharing

## 说明

该目录仅提供 TRA 论文/旧版脚本可能用到的补充数据链接，主要用于：

- 复现/对照论文中的实验设置；
- 或在不依赖 Qlib 默认 `Alpha158/Alpha360` 数据集时做演示。

若你只是想运行 Qlib 基准 workflow（`workflow_config_tra_Alpha158*.yaml` / `workflow_config_tra_Alpha360.yaml`），通常 **不需要** 额外下载本目录数据。
